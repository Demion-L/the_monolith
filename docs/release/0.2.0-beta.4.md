# MONOLITH `0.2.0-beta.4` — Release Notes

**Autonomous Development Governance Framework — Delegate Execution. Retain Understanding.**

**Status:** pre-release for the `beta` dist-tag. MONOLITH is experimental and **not a stable production release**.
Requires Node.js >= 20.

```bash
npm install -g @latysh-development/monolith@beta
```

## Relationship to `0.2.0-beta.3`

The Git tag `v0.2.0-beta.3` (`9d5b333`) exists, but `0.2.0-beta.3` was **never published to npm**; the tag is kept
unchanged. Beta 4 is the first published release after `0.2.0-beta.2` and includes **everything in the
[`0.2.0-beta.3` notes](./0.2.0-beta.3.md)** (Mission Auto-Enrollment, Managed Execution, ownership and handoff,
execution-discipline diagnostics, bypass and parser fixes, new positioning) plus the fix below. Read both documents; the
Beta 3 Known Limitations apply unchanged.

## Fixed

- **Finalize idempotency under YAML reformatting (FIN-003).** A formatter (e.g. Prettier with `singleQuote`) rewriting a
  capsule's `title: "X"` to `title: 'X'` made the next `monolith finalize plan` report a false `capsule` conflict
  (`NOT_READY`). The capsule's flat frontmatter is now compared by decoded value; **only** the quoting style of a quoted
  scalar is ignored. Still a conflict: a changed value (title, Story id, status, date), a missing, added, unknown or
  reordered field, a duplicate key, a type change (`"1"` vs `1`, quoted vs plain), a changed body, and any frontmatter that is not
  a plain flat mapping (compared verbatim). See `docs/reference/cli.md`, "Capsule frontmatter (FIN-003)".

## Compatibility

- Approval digest, plan/apply preconditions, Finalize approval semantics and the create-only capsule rule are unchanged;
  the capsule is never rewritten. Capsules written by earlier versions remain recognised.
- Durable State v3 unchanged; no migration. Managed Execution remains opt-in.

## Known limitations

Those of [`0.2.0-beta.3`](./0.2.0-beta.3.md#known-limitations), unchanged. Additionally: a formatter that rewrites the text
of a *proposal* (e.g. `*` bullets) is not covered by Finalize equivalence, and a plain scalar and a quoted scalar with the same
text are not treated as equal.
